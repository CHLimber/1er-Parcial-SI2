 3. ESPECIFICACION TECNICA
-------------------------------------------------------------------------------

 uso         formato  que es                specs
 ----------  -------  --------------------  ----------------------------------
 AR_OVERLAY  PNG      prenda recortada      1000x1400 px
                                            fondo transparente, max 500 KB
 AR_MODELO   GLB      modelo 3D Android/web max 5 MB, escala en METROS
                                            origen apoyado en el piso, +Y arriba
 AR_MODELO   USDZ     el mismo para iOS     conversion del GLB

 (La especificacion de las fotos CATALOGO esta en CATALOGO_DEMO.txt punto 1.)

 NOMENCLATURA: {codigo}-ar-{color}.{ext}, minusculas y sin acentos.

     blu-001-ar-blanco.png
     bot-001-ar.glb
     bot-001-ar.usdz

 Una fila de producto_imagen por archivo. El color_id es lo que permite tener
 el mismo tapado en negro, camel y vino sin duplicar el producto.

 DONDE ALOJARLOS: igual que las fotos de catalogo, URL ABSOLUTA. El movil no
 comparte origen con la web y el backend no sirve estaticos. Ver
 CATALOGO_DEMO.txt punto 4.6.

 4. EL JSON DE ANCLAJES (formato a definir, hoy nadie lo escribe)
-------------------------------------------------------------------------------

 producto_imagen.anclajes es JSONB libre. Este es el minimo que funciona para
 overlay de torso. Coordenadas NORMALIZADAS de 0 a 1 sobre el PNG, para que no
 dependan de la resolucion:

     {
       "tipo": "TORSO",
       "hombro_izq": { "x": 0.22, "y": 0.16 },
       "hombro_der": { "x": 0.78, "y": 0.16 },
       "cintura":    { "x": 0.50, "y": 0.74 }
     }

 escala_base = ancho real de hombro a hombro en CENTIMETROS, a talla M.
 Para el tapado, unos 42.0.

 PARA QUE SIRVE: con esas dos cosas el overlay se escala solo. La camara
 detecta la distancia entre los hombros de la persona, se compara contra
 escala_base y sale el factor. Sin eso la prenda queda del tamano equivocado
 segun que tan lejos este la clienta de la camara.

 [ ] 4.1  Medir los 3 anclajes sobre cada PNG del punto 1 (se puede a ojo en
          cualquier editor que muestre coordenadas) y anotar su escala_base.
          Solo hace falta si se programa el visor de nivel 1.
